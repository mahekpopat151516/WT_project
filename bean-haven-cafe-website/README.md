# Bean Haven Café

A responsive multi-page café website built with plain HTML, CSS and JavaScript.

## Pages
Home, Menu, Our Story, Speciality, Gallery, Events, Contact, Admin Login, Admin Dashboard.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Admin demo
Open `admin/login.html`
Email: admin@beanhaven.com
Password: admin123

The admin menu demo uses localStorage. There is no backend/database.

## Notes
Images use Unsplash URLs so the project stays lightweight. Replace them with your own licensed images in production.
